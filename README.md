# VideoLoad

App Android tải video bằng yt-dlp (TikTok, YouTube, Facebook, Douyin, Weibo, Bilibili...).

## Build APK bằng GitHub Actions
1. Tạo repo mới trên GitHub (Private cũng được).
2. Upload TOÀN BỘ file/thư mục trong project này lên repo (nhớ cả thư mục `.github`).
3. Vào tab **Actions** -> workflow **Build APK** -> đợi chạy xong (khoảng 5-10 phút).
4. Mở lần chạy đó -> mục **Artifacts** -> tải `VideoLoad-apk` -> giải nén ra file `.apk`.
5. Chép APK vào điện thoại, mở lên, cho phép cài từ nguồn không xác định.
